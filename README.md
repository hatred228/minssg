# minssg

A fast, zero-dependency Markdown Static Documentation Site Generator in Python 3.

## Overview

`minssg` compiles folders of Markdown documents into responsive, dark-themed static HTML documentation sites with sidebar navigation and syntax-highlighted code blocks in milliseconds.

### Highlights

- **Standard Library Only**: No `pip install` required.
- **Modern Developer UI**: Responsive sidebar, clean typography, dark theme.
- **Embedded Dev Server**: Run `python minssg.py serve` to preview your site at `http://127.0.0.1:8000/`.

## Commands

```powershell
# Build markdown into dist/
python minssg.py build

# Build and start local preview server
python minssg.py serve
```
