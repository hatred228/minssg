# Welcome to MinSSG

A minimalist static site generator designed for documentation and technical notes.

## Why MinSSG?

- **Zero dependencies**: Written entirely in pure Python standard library.
- **Fast compile times**: Converts entire documentation sites in under 5 milliseconds.
- **Dark mode by default**: Designed with clean developer aesthetics.

## Quick Example

You can write normal markdown with **bold**, *italic*, inline `code`, and blocks:

```cpp
#include <iostream>

int main() {
    std::cout << "Hello from MinSSG!\n";
    return 0;
}
```
